Canva Layout Specs

Set up your Canva canvas with these grid rules for a perfect A0 visual flow.

  • Page Dimensions: Choose A0 Portrait (84.1 x 118.9 cm) or custom dimensions of 2384 x 3370 pt.
  • Margins: Set document margins to 5% of width (approx. 120 pt in Canva). Keep all structural text within this zone.
  • Font Sizes in Canva:
    • Main Slogan Header: 80pt to 90pt
    • University / Sub-headers: 36pt to 44pt
    • Section Titles: 24pt to 28pt
    • Body Copy: 16pt to 18pt
    • Subtext / Footers: 12pt to 14pt
  • Suggested Font Parings in Canva:
    • Option A (Modern Tech): Space Grotesk (Headers) + Plus Jakarta Sans (Body)
    • Option B (Clean Academic): Outfit (Headers) + Inter (Body)
