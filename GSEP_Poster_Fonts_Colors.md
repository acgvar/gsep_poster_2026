# GSEP Poster Design System: Fonts & Color Palette Guide

This reference document contains the typography hierarchy and hex color codes for each GSEP A0 promotional poster theme. Use these values to perfectly replicate or customize the design in Canva, Adobe Express, Illustrator, or other design tools.

---

## 1. Typography System

All fonts are free, open-source Google Fonts. They can be found directly inside Canva's font search or imported for web/print designs.

### Font Families
1. **Space Grotesk**
   * **Style:** Modern, geometric, clean sans-serif. Excellent for technology or engineering displays.
   * **Used for:** Display headings, program title, and large statistics in the *Cyber Tokyo* theme.
   * **Google Fonts Link:** [Space Grotesk on Google Fonts](https://fonts.google.com/specimen/Space+Grotesk)
2. **Outfit**
   * **Style:** Warm, premium, geometric sans-serif. Great for professional yet inviting layouts.
   * **Used for:** Display headings and section labels in *Sakura Tech* and *Classic Gold* themes.
   * **Google Fonts Link:** [Outfit on Google Fonts](https://fonts.google.com/specimen/Outfit)
3. **Plus Jakarta Sans**
   * **Style:** Highly readable, balanced modern sans-serif. Highly optimized for small screen or print reading.
   * **Used for:** All body copy, details, lists, and statistics descriptions across all three themes.
   * **Google Fonts Link:** [Plus Jakarta Sans on Google Fonts](https://fonts.google.com/specimen/Plus+Jakarta+Sans)

## 2. Text Sizing & Scale (Scaled for A0 Portrait Layout)

When formatting text fields in Canva on an **A0 Canvas** (which has dimensions **84.1 cm x 118.9 cm** or **2384 x 3370 pt**), use the following sizes:

| Element Role | Recommended Font Size | Font Weight Suggestion | Recommended Font Family |
| :--- | :--- | :--- | :--- |
| **Main Program Title** | `80pt - 90pt` | Extra Bold (800) | *Space Grotesk* or *Outfit* |
| **Hero Slogan / Headline** | `24pt - 28pt` | Bold (700) | *Space Grotesk* or *Outfit* |
| **Section Headings** | `24pt - 28pt` | Semi-Bold / Bold (600/700) | *Space Grotesk* or *Outfit* |
| **Large Statistics Callouts** | `24pt - 30pt` | Extra Bold (800) | *Space Grotesk* |
| **Body Copy & List Items** | `16pt - 18pt` | Regular / Medium (400/500) | *Plus Jakarta Sans* |
| **Milestone / Date / Footer** | `12pt - 14pt` | Semi-Bold (600) | *Plus Jakarta Sans* |

## 3. Theme Color Palettes (Hex Codes)

To recreate the exact styling of each layout, use the following Hex color values:

### A. Theme 1: Cyber Tokyo (Light Edition)
*Ideal for a modern, high-tech, and futuristic look while remaining readable.*

* **Background (Base):** `#f8fafc` (Canva Gradient: `#f0f9ff` to `#e0f2fe`)
* **Card Panels (Containers):** `#ffffff` (Set opacity to **85%** / transparent fill)
* **Primary Accent (Headers/Highlights):** `#0284c7` (Sky Blue)
* **Secondary Accent (Callouts/Dates):** `#ea580c` (Electric Orange)
* **Main Text Color:** `#0f172a` (Dark Slate)
* **Muted/Secondary Text:** `#475569` (Slate Gray)

### B. Theme 2: Sakura Tech
*Ideal for a soft, friendly look inspired by Japan's iconic cherry blossoms.*

* **Background (Base):** `#fff5f7` (Canva Gradient: `#fff5f7` to `#fff1f2`)
* **Card Panels (Containers):** `#ffffff` (Set opacity to **90%** / transparent fill)
* **Primary Accent (Headers/Highlights):** `#db2777` (Deep Pink)
* **Secondary Accent (Callouts/Dates):** `#f43f5e` (Rose Pink)
* **Main Text Color:** `#3c091f` (Deep Plum)
* **Muted/Secondary Text:** `#831843` (Deep Magenta Muted)

### C. Theme 3: Classic Gold (Ivory Edition)
*Ideal for a prestigious, academic, and highly traditional presentation style.*

* **Background (Base):** `#faf9f5` (Canva Gradient: `#faf9f5` to `#f3ede2`)
* **Card Panels (Containers):** `#ffffff` (Set opacity to **90%** / transparent fill)
* **Primary Accent (Headers/Highlights):** `#b8901c` (Prestige Gold)
* **Secondary Accent (Callouts/Dates):** `#d97706` (Warm Amber)
* **Main Text Color:** `#0f1c3f` (Dark Navy)
* **Muted/Secondary Text:** `#3a506b` (Classic Slate Blue)
